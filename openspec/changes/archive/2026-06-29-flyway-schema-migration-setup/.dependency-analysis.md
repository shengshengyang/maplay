# Flyway 遷移檔案靜態分析報告

## 檔案清單與依賴關係

### V1__enable_postgis.sql
- **功能**: 啟用 PostGIS 與 pgcrypto extensions
- **依賴**: 無 (基礎遷移)
- **建立**: PostGIS, pgcrypto extensions

### V2__create_users.sql  
- **功能**: 建立使用者表
- **依賴**: 無 (基礎資料表)
- **建立**: users 表
- **約束**: email 部分唯一索引, provider identity 唯一索引

### V3__create_refresh_tokens.sql
- **功能**: 建立更新權杖表
- **依賴**: V2 (users)
- **FK 關係**: `user_id REFERENCES users (id) ON DELETE CASCADE`
- **索引**: token_hash 唯一索引, user_id 索引

### V4__create_spots.sql
- **功能**: 建立景點表
- **依賴**: V2 (users)
- **FK 關係**: 
  - `submitted_by REFERENCES users (id) ON DELETE SET NULL`
  - `reviewed_by REFERENCES users (id) ON DELETE SET NULL`
- **索引**: location GIST 索引, gov_data_id 部分唯一索引, status 等複合索引

### V5__create_spot_images.sql
- **功能**: 建立景點圖片表
- **依賴**: V4 (spots), V2 (users)
- **FK 關係**:
  - `spot_id REFERENCES spots (id) ON DELETE CASCADE`
  - `uploaded_by REFERENCES users (id) ON DELETE SET NULL`
- **索引**: spot_id 索引, is_cover 部分唯一索引

### V6__create_reviews.sql
- **功能**: 建立評價表
- **依賴**: V4 (spots), V2 (users)
- **FK 關係**:
  - `spot_id REFERENCES spots (id) ON DELETE CASCADE`
  - `user_id REFERENCES users (id) ON DELETE CASCADE`
- **約束**: (spot_id, user_id) 唯一約束, rating/clean_level CHECK 約束
- **索引**: spot_id, user_id 索引

### V7__create_import_history.sql
- **功能**: 建立匯入歷史表
- **依賴**: V2 (users)
- **FK 關係**: `operated_by REFERENCES users (id) ON DELETE SET NULL`
- **索引**: created_at DESC 索引

## 依賴關係圖

```
V1 (extensions) → V2 (users) → V3 (refresh_tokens)
                              ↓
                              V4 (spots) → V5 (spot_images)
                                      ↓
                                      V6 (reviews)
                              
                              V2 (users) → V7 (import_history)
```

## 結論
- ✅ 所有遷移檔案版本號順序正確
- ✅ FK 依賴關係正確，無循環依賴
- ✅ 版本號遵循遞增整數格式 (V1-V7)
- ✅ 檔案描述使用 snake_case 命名慣例
