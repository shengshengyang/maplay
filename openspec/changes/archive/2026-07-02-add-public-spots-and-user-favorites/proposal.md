## Why

目前景點查看功能需要登入才能使用，這限制了用戶在未登入狀態下瀏覽景點信息的能力。同時，登入用戶缺乏收藏景點的功能，無法追蹤感興趣的地點。為了提升用戶體驗和增加平台粘性，需要將景點查看對所有用戶開放，並為登入用戶提供個人收藏管理功能。

## What Changes

- **移除景點查看的認證要求**：景點列表、詳情、搜索等查詢類 API 改為公開訪問，無需 JWT token
- **新增用戶收藏功能**：登入用戶可以收藏/取消收藏景點，查看個人收藏列表
- **調整權限策略**：查詢類端點允許匿名訪問，收藏/評價等操作類端點仍需認證
- **優化前端體驗**：未登入用戶可瀏覽，登入後顯示收藏狀態和收藏管理功能

## Capabilities

### New Capabilities
- `user-favorites`: 用戶收藏景點功能，包括收藏/取消收藏操作、個人收藏列表查詢、檢查景點收藏狀態

### Modified Capabilities
- `spot-management`: 調整整體景點查詢 API 的權限策略，從需要認證改為公開訪問

## Impact

**API 層面**：
- `/api/spots/*` 查詢類端點移除 `[Authorize]` 標記
- 新增 `/api/favorites/*` 端點組，需要認證
- JWT token 對收藏相關操作仍為必須

**資料庫層面**：
- 新增 `user_favorites` 表，存儲用戶與景點的收藏關聯
- 添加索引以支持高效查詢（user_id, spot_id）

**前端層面**：
- 未登入狀態可瀏覽景點，收藏功能隱藏或引導登入
- 登入後顯示��藏按鈕狀態和收藏列表入口
- 需處理登入前後的狀態同步

**依賴與風險**：
- 需要確保公開訪問的景點數據不包含敏感信息（如管理標記、審查狀態等）
- 收藏功能需要級聯刪除處理（景點刪除時清理相關收藏記錄）

## Non-goals (本期不做)

- 社群分享收藏列表
- 收藏分類/標籤功能
- 收藏統計與推薦
- 公開收藏頁面（僅限���人查看）
